# Midterm Report Guidelines

Due on Novermber 1ast: project midterm report
Each group only needs to submit one report. Please submit the PDF file with a cover letter. You may
use LaTeX or Word to finish the proposal.

1. The cover letter should have the project title and team members;
2. The project proposal's main content needs to contain the following:
   1. Introduction - In this session, you need to introduce your group and an idea of the project briefly. What questions do you plan to ask in this project or what topic will you focus on? Why do we care about this topic?
   2. Related Work - In this session, you need to provide at least five articles related to your project and briefly describe each article’s contribution. Please review at least 5 related work (5 references you use). Summarize each reference in 2-3 sentences and summarize how they relate to your work.
   3. Methodology - In this session, you need to give the outline of the methodology you will use or introduce for your project. Here you need to list the method you plan to use (for example: Artifical Nueral Network, Decision trees or any others).
   4. Experiments (if applicable) - If you have any computational experiments, please describe how you want to perform the experiments, such as data collection, the package you need, etc. I will not expect you to finish the experiments or get any analysis at this time. But please briefly explain your workflow. If you could provide a workflow chart, that would be great. If you do not know how to do a flowchart, don't worry. You can explain your method, how to apply it to your data, and what your expectations are.
   5. TimeLine and teamwork plan - Give a brief timeline for your project and each member's contribution (tentative). How do you plan to finish the project by week 15? What is the responsibility for each group member?
   6. Reference - Make sure you need at least five articles. Proper citation and format are required. You can use APA, Chicago, MLA, etc. If you need help:

[](https://libguides.brown.edu/citations/styles)

Upon completion of this project, each student will be able to:
- Select and define a problem to be solved.
- Identify multiple relevant resources of literature.
- Integrate mathematical concepts appropriately.
- Present technical material in written form, using one of the formats for the standard scientific
journals.

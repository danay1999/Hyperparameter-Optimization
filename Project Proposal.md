# Project Proposal

## Project Goal

The goal of our final project is to compare different hyperparameter optimization methods:

- Grid search
- Random search
- Bayesian optimization
- Successive halving

## Methodology

We will give each optimizer an equivalent "time budget", and we will compare:

- Predictive performance
- Optimization time
- Convergence speed
- Stability across different runs

The idea is to compare these optimization methods with different types of regression and
classification datasets: small x big data, clean x noisy data, low x high dimensionality, etc.

## Expected Outcome

The goal is to determine how each optimization strategy performs based on the model, data
characteristics, and computational budget.
